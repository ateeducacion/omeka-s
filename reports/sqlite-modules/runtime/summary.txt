FALLOS CONFIRMADOS
Collecting: Module.php:41 crea collecting_form con COLLATE `utf8mb4_unicode_ci`.
La traducción elimina ENGINE y CHARACTER SET, pero conserva COLLATE cuando su
nombre está entre comillas. SQLite devuelve "near COLLATE: syntax error".
Es una carencia del traductor del núcleo. Después de resolverla, las llamadas
ADD CONSTRAINT FOREIGN KEY de las líneas 46 y siguientes seguirán pendientes.

CSV Import: Module.php:44 usa ALTER TABLE ... ADD CONSTRAINT ... FOREIGN KEY.
Las tablas se crean, pero el adaptador rechaza expresamente la operación porque
SQLite requiere definir la clave en CREATE TABLE o reconstruir la tabla.
No es correcto omitir la consulta: se perdería integridad referencial.
